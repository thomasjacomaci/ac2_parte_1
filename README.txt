CADASTRO DE FRUTAS - VERSÃO ATUALIZADA

1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. No terminal, execute:
   npm install

4. Depois execute:
   ng serve

5. Abra:
   http://localhost:4200

Nesta versão o cadastro e a listagem aparecem na mesma página.
Ao cadastrar uma fruta, ela aparece logo abaixo em "Frutas cadastradas".
